# bh-peiliao — BH型鋼鋼板配料系統

將 BH 型鋼構件拆成翼板 / 腹板，自動計算鋼板採購與切割配料（優先使用現有餘料），並輸出報表。

| 檔案 | 說明 |
|---|---|
| `BH配料系統.html` | 網頁版（雙擊即可用瀏覽器開啟，建議 Chrome / Edge） |
| `BH_GUI.py` | 桌面版（Python / Tkinter，需安裝 Python 3.12 以上） |

## 主要功能
- BH 配料表、現有餘料輸入（可匯入 CSV）
- 單段 / 多段切割配料最佳化（600 次隨機排列取最省料方案）
- 配料結果預覽、多段切割排列圖
- 匯出 Excel 報表、PDF、排列圖、信暐訂購單
- 採購修正（調整板寬 / 板長後重新產生報表）
- 進度檔 JSON（網頁版與桌面版互通）
