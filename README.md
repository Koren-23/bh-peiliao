# bh-peiliao — BH型鋼鋼板配料系統

將 BH 型鋼構件拆成翼板 / 腹板，自動計算鋼板採購與切割配料（優先使用現有餘料），並輸出報表。

| 檔案 | 說明 |
|---|---|
| `BH配料系統.html` | 網頁版（雙擊即可用瀏覽器開啟，建議 Chrome / Edge） |
| `BH_GUI.py` | 桌面版（Python / Tkinter，需安裝 Python 3.12 以上） |
| `tests/` | 自動化測試 |

## 主要功能
- BH 配料表、現有餘料輸入（可匯入 CSV）
- 單段 / 多段切割配料最佳化（多段切割：每種規格以數種排列策略各排一次，取總板重最小的方案）
- 配料結果預覽、切割排列圖（含餘料、修邊、鋸縫）
- 損耗分析：每張板的損耗原因（修邊鋸縫、排列長短不一、板長 / 板寬補到最小值、重量不足加寬、採購修正調整）與加大原因說明，可匯出 Excel
- 匯出 Excel 報表、PDF、排列圖、信暐訂購單
- 採購修正（調整板寬 / 板長後重新產生報表）
  - 數量改小可拆分：同規格多片只修改其中幾片，其餘自動另成一列並保留原尺寸；「片次」欄顯示每列對應的切割片次
  - 尺寸不足（切不下零件）會阻擋完成；超出採購限制會提醒並標紅，可選擇「忽略」（琥珀色顯示）後繼續
  - 不同材質各自成列，修改與拆分互不影響
- 進度檔 JSON（網頁版與桌面版互通）

網頁版：https://koren-23.github.io/bh-peiliao/

## 測試

網頁版與桌面版的計算邏輯逐行對應，修改任一邊都必須同步修改另一邊，並執行測試：

```
python -m unittest discover -s tests -v
```

- 回歸測試：曾經發生過的 bug 不再出現
- 一致性：切割明細餘料 = 餘料清單 = 排列圖
- 網頁版 / 桌面版比對：以 Node.js 執行網頁版計算核心，與桌面版跑相同的隨機案例，結果必須完全相同（未安裝 Node.js 時略過此項）
